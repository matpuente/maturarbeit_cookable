# Testliste Cookable – iPad

Gerät: iPad, iPadOS 27.2 · Version: Stand 18. November 2026

Die Funktionen sind dieselben wie auf dem iPhone (siehe `Testliste_iPhone.md`). Diese Liste prüft vor allem, was auf dem iPad anders ist: grösserer Bildschirm, Liste und Rezept nebeneinander, Hoch- und Querformat.

Jeden Punkt abhaken, wenn das erwartete Ergebnis eintritt. Wenn nicht: kurz notieren, was passiert ist (am besten mit Bildschirmfoto).

Hinweis: Auf dem iPad beginnt die App mit einem leeren Vorrat (keine Synchronisierung mit dem iPhone).

---

## 1. Installation und Start

- [x] Die App heisst auf dem Home-Bildschirm **Cookable** und hat das grüne Kochtopf-Symbol.
- [x] Die App startet ohne Absturz.
- [x] Es gibt fünf Tabs: **Start · Vorrat · Rezepte · Favoriten · Einkaufsliste**.
- [x] Die Tabs sind gut erreichbar (oben oder unten, je nach iPadOS-Darstellung).
- [x] «Immer zuhause» enthält die 7 Grundzutaten.

## 2. Hoch- und Querformat

- [x] Jeder Tab sieht im **Hochformat** ordentlich aus (nichts abgeschnitten, keine riesigen Lücken).
- [x] Jeder Tab sieht im **Querformat** ordentlich aus.
- [x] Drehen während ein Fenster offen ist (z. B. «Zutat hinzufügen») → kein Absturz, Eingaben bleiben erhalten.

## 3. Vorrat

- [x] Einige Zutaten an verschiedenen Lagerorten hinzufügen, eine davon mit Ablaufdatum **morgen**.
- [x] Das Fenster «Zutat hinzufügen» erscheint als Fenster in der Mitte (nicht bildschirmfüllend) und lässt sich gut bedienen.
- [x] Die Tastatur verdeckt die Trefferliste nicht.
- [x] Die Zutat mit Ablaufdatum morgen ist **orange** markiert.
- [x] «Bearbeiten» → rote Minus-Knöpfe → Löschen funktioniert.

## 4. Rezepte – Liste und Rezept nebeneinander

- [x] Im Querformat stehen **Liste links und Rezept rechts** nebeneinander.
- [x] Ohne Auswahl steht rechts «Kein Rezept ausgewählt».
- [x] Ein Rezept antippen → es erscheint rechts, die Liste bleibt sichtbar.
- [x] Ein anderes Rezept antippen → rechts wechselt es sofort (richtiges Foto, richtige Zutaten).
- [x] Im Hochformat: Liste und Rezept lassen sich gut wechseln (Zurück-Knopf oder Seitenleiste).
- [x] Filter (Zeit, Kategorie, «Muss enthalten») und Suche funktionieren; die Fenster erscheinen ordentlich.
- [x] Die Fotos in der Liste und im Rezept sind scharf und nicht verzerrt.

## 5. Rezept-Detailansicht

- [x] Foto, Zutaten, Anleitung und Nährwerte sind gut lesbar (Zeilen nicht zu breit).
- [x] Die Übersetzung erscheint beim ersten Öffnen; «Original» zeigt den englischen Text.
- [x] Portionsrechner ändert die Mengen.
- [x] Herz → Rezept erscheint im Tab **Favoriten**.
- [x] **Fehlende Zutaten auf die Einkaufsliste** → am Tab «Einkaufsliste» erscheint die Zahl.
- [x] **Gekocht – Vorrat aktualisieren** → Fenster erscheint, entfernen und «Rückgängig» funktionieren; die Meldung ist gut sichtbar.

## 6. Startseite

- [x] «Bald ablaufend» zeigt die Zutat von morgen (orange).
- [x] Die Foto-Karten (Rezepte zum Aufbrauchen, Passt zu deinem Vorrat, Schnell gemacht, Favoriten) sind ordentlich angeordnet und lassen sich seitlich wischen.
- [x] Eine Karte antippen öffnet das Rezept.

## 7. Favoriten

- [x] Liste und Rezept nebeneinander wie bei «Rezepte».
- [x] Sortierung «Passt am besten» / «Zuletzt hinzugefügt» funktioniert.
- [x] Herz im geöffneten Rezept antippen → das Rezept bleibt offen (verschwindet nicht).

## 8. Einkaufsliste

- [x] «Alle Zutaten» und «Nach Rezept» funktionieren.
- [x] Abhaken → «Im Wagen»; «Gekaufte in den Vorrat» legt die Zutaten in den Vorrat.
- [x] **+** öffnet das Fenster «Hinzufügen» ordentlich.
- [x] «Liste teilen» öffnet das Teilen-Fenster (auf dem iPad als kleines Fenster beim Knopf).

## 9. Mitteilungen

- [x] Beim ersten Ablaufdatum fragt iPadOS nach der Erlaubnis für Mitteilungen → **Erlauben**.
- [x] Glocke im Vorrat → Uhrzeit auf 2–3 Minuten später → Mitteilung kommt.
- [x] Antippen der Mitteilung öffnet die App auf der **Startseite** (kein Absturz).
- [x] Danach Uhrzeit wieder auf 17:00.

## 10. Hell und dunkel

- [x] Im **Dunkelmodus** (Kontrollzentrum) ist alles gut lesbar, Grün ist heller.
- [ ] Das App-Symbol hat die dunkle Variante.

---

## Notizen
Löschen der Zutaten mit nach rechts wischen funktioniert nicht.
Welches app symbol meinen sie? Es bleibt gleich.
