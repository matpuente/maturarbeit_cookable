# Testliste Cookable – iPhone

Gerät: iPhone 12 mini, iOS 26.6 · Version: Stand 15. November 2026

Jeden Punkt abhaken, wenn das erwartete Ergebnis eintritt. Wenn nicht: kurz notieren, was passiert ist (am besten mit Bildschirmfoto).

---

## 1. Start und Grundlagen

- [x] Auf dem Home-Bildschirm heisst die App **Cookable**.
- [x] Die App startet ohne Absturz und zeigt den Tab **Vorrat**.
- [x] Unten gibt es zwei Tabs: **Vorrat** und **Rezepte**.
- [x] Alle Texte der Oberfläche sind Deutsch.
- [x] Im Vorrat steht oben **Immer zuhause** mit den Grundzutaten (bzw. denen, die du nicht gelöscht hast).

## 2. Vorrat

### Zutat hinzufügen

- [x] **+** oben rechts öffnet «Zutat hinzufügen», das Suchfeld ist aktiv, die Tastatur erscheint.
- [x] «zwieb» zeigt Zwiebel, rote Zwiebel, Frühlingszwiebel … – häufige Zutaten zuerst.
- [x] Gross-/Kleinschreibung und Akzente spielen keine Rolle (z. B. «jalapeno» findet Jalapeño).
- [x] Eine Fantasie-Eingabe (z. B. «xyz») zeigt «Keine passende Zutat gefunden».
- [x] Eine Zutat, die schon im Vorrat ist, zeigt darunter «Bereits im Vorrat: …».

### Lagerort-Vorschlag

- [x] **Kartoffel** wählen → Lagerort springt auf **Vorratsschrank**.
- [x] **Butter** wählen → **Kühlschrank**.
- [x] **Erbsen** wählen → **Tiefkühler**.
- [x] Eine Zutat an einen anderen Ort legen (z. B. Äpfel in den Kühlschrank) und hinzufügen. Später dieselbe Zutat nochmals wählen → dein Ort wird vorgeschlagen.

### Ablaufdatum und Doppel

- [x] Schalter **Ablaufdatum** einschalten → Datum erscheint (Format 17.11.2026), lässt sich ändern.
- [x] Nach dem Hinzufügen steht «Läuft ab am …» unter der Zutat.
- [x] Dieselbe Zutat nochmals am selben Lagerort hinzufügen → rote Meldung, «Hinzufügen» ist gesperrt.
- [x] Dieselbe Zutat an einem anderen Lagerort → erlaubt.

### Bearbeiten und Löschen

- [x] Auf eine Zutat tippen → «Zutat bearbeiten»; Lagerort ändern und sichern → Zutat steht unter dem neuen Lagerort.
- [x] Im Bearbeiten-Fenster «Aus dem Vorrat entfernen» → Zutat ist weg.
- [x] Zutat nach links wischen → **Löschen** → Zutat ist weg, die übrigen Zeilen stimmen (keine doppelten oder fehlenden).
- [x] **Bearbeiten** oben links → mehrere Zutaten auf einmal löschen.

### Immer zuhause

- [x] Tippen auf «Immer zuhause» klappt die Liste auf und zu.
- [x] Eine Grundzutat löschen (z. B. Mehl) → verschwindet, die Liste stimmt.
- [x] Das blaue **⊕** öffnet «Zutat hinzufügen» mit Lagerort «Immer zuhause»; eine Zutat hinzufügen (z. B. Butter) → erscheint in «Immer zuhause» ohne Ablaufdatum.
- [x] Die gelöschte Grundzutat lässt sich wieder hinzufügen (in der Suche mit Hinweis «Grundzutat»).

### Speichern

- [x] App ganz schliessen (vom unteren Rand nach oben wischen, App wegwischen) und neu öffnen → Vorrat ist unverändert.

## 3. Rezepte

### Liste

- [x] Tab **Rezepte** zeigt die Anzahl («… Rezepte») und eine Liste.
- [x] Die Rezeptnamen erscheinen nach 1–2 Sekunden auf Deutsch (Schweizer Begriffe: Poulet, Rahm, Zucchetti).
- [x] Jede Zeile zeigt «X von Y Zutaten vorhanden», einen Balken, die Zeit und die Kategorie.
- [x] Bei austauschbaren Zutaten steht «· 1 Ersatz» (z. B. Spaghetti-Rezept, wenn du Penne hast).
- [x] Ganz oben stehen Rezepte mit dem höchsten Anteil vorhandener Zutaten.
- [x] Eine neue Zutat zum Vorrat hinzufügen → die Rezeptliste passt sich an.

### Filter

- [x] Zeit: **Alle / ≤ 15 / ≤ 30 / ≤ 60 / > 60** – die Anzahl ändert sich, die Zeiten in der Liste passen.
- [x] Kategorie: **Frühstück, Hauptgericht, Beilage, Dessert, Snack** – nur Rezepte dieser Kategorie.
- [x] App neu starten → Zeit- und Kategoriefilter sind noch gesetzt.

### Muss enthalten

- [x] **Muss enthalten** öffnet die Auswahl, nach Lagerort gruppiert, mit Suchfeld und Ablaufdatum.
- [x] Suchfeld in der Auswahl filtert die Zutaten.
- [x] Zwei Zutaten wählen (z. B. Rinderhackfleisch und Kartoffel) → nur Rezepte mit beiden; die mit genau diesen Zutaten zuerst, danach die mit Ersatz.
- [x] Gewählte Zutaten erscheinen als blaue Knöpfe; Tippen auf «×» entfernt sie.
- [x] «Zurücksetzen» leert die Auswahl.

### Suche

- [x] Suchfeld «Rezept oder Zutat suchen»: «lasagna» findet Lasagne-Rezepte.
- [x] Ein deutscher Name, der schon übersetzt wurde (z. B. «Poulet»), findet passende Rezepte.
- [x] Eine deutsche Zutat (z. B. «Zucchetti») findet Rezepte mit dieser Zutat – auch solche, für die du nichts im Vorrat hast.
- [x] Unsinnige Suche → Hinweis «Keine Rezepte für …».

## 4. Detailansicht

- [x] Rezept antippen → Foto oben (oder Platzhalter mit Besteck, wenn keines vorhanden ist).
- [x] Beim ersten Öffnen kurz «Wird übersetzt …», danach Name, Zutaten und Anleitung auf Deutsch.
- [x] Die Anleitung ist in Du-Form, Temperaturen in °C, unten «Übersetzt mit DeepL».
- [x] **Original** oben rechts zeigt den englischen Text, **Deutsch** schaltet zurück.
- [x] Zutaten mit sinnvollen Mengen: ml/g statt Cups und Ounces, EL/TL, Brüche (½, ¼), Einheiten auf Deutsch (Dose, Packung, Zehe …).
- [x] Vorhandene Zutaten haben ein grünes ✓, Ersatz ein oranges Symbol mit «Ersatz: du hast …».
- [x] Portionsrechner **+** / **−** rechnet alle Mengen um; «Zurück auf X Portionen» stellt zurück.
- [x] Nährwerte pro Portion (Energie, Fett, Kohlenhydrate, Eiweiss …) werden angezeigt und ändern sich mit dem Portionsrechner nicht.
- [x] Dasselbe Rezept nochmals öffnen → sofort auf Deutsch (ohne «Wird übersetzt …»).

## 5. Ohne Internet (Flugmodus)

- [x] Flugmodus ein (und WLAN aus). Ein **noch nie geöffnetes** Rezept öffnen → englischer Text, oben «Keine Internetverbindung – das Rezept wird auf Englisch angezeigt» mit «Erneut versuchen».
- [x] Ein **schon geöffnetes** Rezept → bleibt auf Deutsch, das Foto ist noch da. 
- [x] In der Rezeptliste nach unten scrollen zu nicht übersetzten Namen → Hinweis über der Liste, Namen auf Englisch.
- [x] Vorrat, Filter, Suche und Portionsrechner funktionieren auch ohne Internet.
- [x] Flugmodus aus → «Erneut versuchen» tippen → Rezept wird übersetzt.

## 6. Darstellung und Bedienung

- [x] iPhone quer halten → Vorrat, Rezepte und Detailansicht sind gut lesbar.
- [x] Dunkelmodus (Kontrollzentrum oder Einstellungen → Anzeige & Helligkeit) → alles lesbar, keine weissen Flächen mit weisser Schrift.
- [x] Grosse Schrift (Einstellungen → Anzeige & Helligkeit → Textgrösse) → Texte werden grösser, nichts Wichtiges wird abgeschnitten.
- [x] Die App reagiert flüssig: Liste scrollen, Filter wechseln, Suchen ohne spürbare Verzögerung.
