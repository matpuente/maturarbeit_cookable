# Testliste Cookable – iPhone

Gerät: iPhone 12 mini, iOS 26.6 · Version: Stand 15. November 2026

Jeden Punkt abhaken, wenn das erwartete Ergebnis eintritt. Wenn nicht: kurz notieren, was passiert ist (am besten mit Bildschirmfoto).

---

## 1. Start und Grundlagen

- [ ] Auf dem Home-Bildschirm heisst die App **Cookable**.
- [ ] Die App startet ohne Absturz und zeigt den Tab **Vorrat**.
- [ ] Unten gibt es zwei Tabs: **Vorrat** und **Rezepte**.
- [ ] Alle Texte der Oberfläche sind Deutsch.
- [ ] Im Vorrat steht oben **Immer zuhause** mit den Grundzutaten (bzw. denen, die du nicht gelöscht hast).

## 2. Vorrat

### Zutat hinzufügen

- [ ] **+** oben rechts öffnet «Zutat hinzufügen», das Suchfeld ist aktiv, die Tastatur erscheint.
- [ ] «zwieb» zeigt Zwiebel, rote Zwiebel, Frühlingszwiebel … – häufige Zutaten zuerst.
- [ ] Gross-/Kleinschreibung und Akzente spielen keine Rolle (z. B. «jalapeno» findet Jalapeño).
- [ ] Eine Fantasie-Eingabe (z. B. «xyz») zeigt «Keine passende Zutat gefunden».
- [ ] Eine Zutat, die schon im Vorrat ist, zeigt darunter «Bereits im Vorrat: …».

### Lagerort-Vorschlag

- [ ] **Kartoffel** wählen → Lagerort springt auf **Vorratsschrank**.
- [ ] **Butter** wählen → **Kühlschrank**.
- [ ] **Erbsen** wählen → **Tiefkühler**.
- [ ] Eine Zutat an einen anderen Ort legen (z. B. Äpfel in den Kühlschrank) und hinzufügen. Später dieselbe Zutat nochmals wählen → dein Ort wird vorgeschlagen.

### Ablaufdatum und Doppel

- [ ] Schalter **Ablaufdatum** einschalten → Datum erscheint (Format 17.11.2026), lässt sich ändern.
- [ ] Nach dem Hinzufügen steht «Läuft ab am …» unter der Zutat.
- [ ] Dieselbe Zutat nochmals am selben Lagerort hinzufügen → rote Meldung, «Hinzufügen» ist gesperrt.
- [ ] Dieselbe Zutat an einem anderen Lagerort → erlaubt.

### Bearbeiten und Löschen

- [ ] Auf eine Zutat tippen → «Zutat bearbeiten»; Lagerort ändern und sichern → Zutat steht unter dem neuen Lagerort.
- [ ] Im Bearbeiten-Fenster «Aus dem Vorrat entfernen» → Zutat ist weg.
- [ ] Zutat nach links wischen → **Löschen** → Zutat ist weg, die übrigen Zeilen stimmen (keine doppelten oder fehlenden).
- [ ] **Bearbeiten** oben links → mehrere Zutaten auf einmal löschen.

### Immer zuhause

- [ ] Tippen auf «Immer zuhause» klappt die Liste auf und zu.
- [ ] Eine Grundzutat löschen (z. B. Mehl) → verschwindet, die Liste stimmt.
- [ ] Das blaue **⊕** öffnet «Zutat hinzufügen» mit Lagerort «Immer zuhause»; eine Zutat hinzufügen (z. B. Butter) → erscheint in «Immer zuhause» ohne Ablaufdatum.
- [ ] Die gelöschte Grundzutat lässt sich wieder hinzufügen (in der Suche mit Hinweis «Grundzutat»).

### Speichern

- [ ] App ganz schliessen (vom unteren Rand nach oben wischen, App wegwischen) und neu öffnen → Vorrat ist unverändert.

## 3. Rezepte

### Liste

- [ ] Tab **Rezepte** zeigt die Anzahl («… Rezepte») und eine Liste.
- [ ] Die Rezeptnamen erscheinen nach 1–2 Sekunden auf Deutsch (Schweizer Begriffe: Poulet, Rahm, Zucchetti).
- [ ] Jede Zeile zeigt «X von Y Zutaten vorhanden», einen Balken, die Zeit und die Kategorie.
- [ ] Bei austauschbaren Zutaten steht «· 1 Ersatz» (z. B. Spaghetti-Rezept, wenn du Penne hast).
- [ ] Ganz oben stehen Rezepte mit dem höchsten Anteil vorhandener Zutaten.
- [ ] Eine neue Zutat zum Vorrat hinzufügen → die Rezeptliste passt sich an.

### Filter

- [ ] Zeit: **Alle / ≤ 15 / ≤ 30 / ≤ 60 / > 60** – die Anzahl ändert sich, die Zeiten in der Liste passen.
- [ ] Kategorie: **Frühstück, Hauptgericht, Beilage, Dessert, Snack** – nur Rezepte dieser Kategorie.
- [ ] App neu starten → Zeit- und Kategoriefilter sind noch gesetzt.

### Muss enthalten

- [ ] **Muss enthalten** öffnet die Auswahl, nach Lagerort gruppiert, mit Suchfeld und Ablaufdatum.
- [ ] Suchfeld in der Auswahl filtert die Zutaten.
- [ ] Zwei Zutaten wählen (z. B. Rinderhackfleisch und Kartoffel) → nur Rezepte mit beiden; die mit genau diesen Zutaten zuerst, danach die mit Ersatz.
- [ ] Gewählte Zutaten erscheinen als blaue Knöpfe; Tippen auf «×» entfernt sie.
- [ ] «Zurücksetzen» leert die Auswahl.

### Suche

- [ ] Suchfeld «Rezept oder Zutat suchen»: «lasagna» findet Lasagne-Rezepte.
- [ ] Ein deutscher Name, der schon übersetzt wurde (z. B. «Poulet»), findet passende Rezepte.
- [ ] Eine deutsche Zutat (z. B. «Zucchetti») findet Rezepte mit dieser Zutat – auch solche, für die du nichts im Vorrat hast.
- [ ] Unsinnige Suche → Hinweis «Keine Rezepte für …».

## 4. Detailansicht

- [ ] Rezept antippen → Foto oben (oder Platzhalter mit Besteck, wenn keines vorhanden ist).
- [ ] Beim ersten Öffnen kurz «Wird übersetzt …», danach Name, Zutaten und Anleitung auf Deutsch.
- [ ] Die Anleitung ist in Du-Form, Temperaturen in °C, unten «Übersetzt mit DeepL».
- [ ] **Original** oben rechts zeigt den englischen Text, **Deutsch** schaltet zurück.
- [ ] Zutaten mit sinnvollen Mengen: ml/g statt Cups und Ounces, EL/TL, Brüche (½, ¼), Einheiten auf Deutsch (Dose, Packung, Zehe …).
- [ ] Vorhandene Zutaten haben ein grünes ✓, Ersatz ein oranges Symbol mit «Ersatz: du hast …».
- [ ] Portionsrechner **+** / **−** rechnet alle Mengen um; «Zurück auf X Portionen» stellt zurück.
- [ ] Nährwerte pro Portion (Energie, Fett, Kohlenhydrate, Eiweiss …) werden angezeigt und ändern sich mit dem Portionsrechner nicht.
- [ ] Dasselbe Rezept nochmals öffnen → sofort auf Deutsch (ohne «Wird übersetzt …»).

## 5. Ohne Internet (Flugmodus)

- [ ] Flugmodus ein (und WLAN aus). Ein **noch nie geöffnetes** Rezept öffnen → englischer Text, oben «Keine Internetverbindung – das Rezept wird auf Englisch angezeigt» mit «Erneut versuchen».
- [ ] Ein **schon geöffnetes** Rezept → bleibt auf Deutsch, das Foto ist noch da.
- [ ] In der Rezeptliste nach unten scrollen zu nicht übersetzten Namen → Hinweis über der Liste, Namen auf Englisch.
- [ ] Vorrat, Filter, Suche und Portionsrechner funktionieren auch ohne Internet.
- [ ] Flugmodus aus → «Erneut versuchen» tippen → Rezept wird übersetzt.

## 6. Darstellung und Bedienung

- [ ] iPhone quer halten → Vorrat, Rezepte und Detailansicht sind gut lesbar.
- [ ] Dunkelmodus (Kontrollzentrum oder Einstellungen → Anzeige & Helligkeit) → alles lesbar, keine weissen Flächen mit weisser Schrift.
- [ ] Grosse Schrift (Einstellungen → Anzeige & Helligkeit → Textgrösse) → Texte werden grösser, nichts Wichtiges wird abgeschnitten.
- [ ] Die App reagiert flüssig: Liste scrollen, Filter wechseln, Suchen ohne spürbare Verzögerung.
